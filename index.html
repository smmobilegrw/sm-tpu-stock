Google Sheet Connect Karne ka Asaan Tareeqa

  1. Apne Gmail se Google Sheets mein nayi sheet banayein (naam: SM TPU Inventory).
  2. Menu mein Extensions → Apps Script kholein.
  3. Project folder mein di gayi google-apps-script/Code.gs file ka code wahan paste karke Save karein.
  4. Apps Script mein Deploy → New deployment → Web app select karein (Execute as: Me, Who has access: Anyone).
  5. Jo URL mile usay upar paste karein aur Save & Test URL dabayein.
  6. Phir Push Stock to Sheet dabayein — saare 284 models aapki Google Sheet mein chale jayenge!
  7. Google Sheet reload karke menu SM TPU App → 2. Enable Daily Auto-Backup par click kar dein.
